### 2.3 目录归属判定规则（避免争议）

| 判定问题                                             | 规则                                                                                           |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 放 `ui/` 还是 `sections/`？                          | 组件内**出现任何中文业务文案**（如「云服务器」「立即购买」）→ `sections/`；否则 → `ui/`        |
| 放 `sections/shared` 还是 `sections/home`？          | 被 ≥ 2 个路由引用 → `shared/`；仅 1 个路由引用 → 该路由对应的子目录                            |
| 放 `app/xxx/sections/` 还是 `components/sections/`？ | 组件与父页面强耦合且**仅此一处使用** → 就近放页面目录；否则 → `components/`                    |
| 逻辑放 `hooks/` 还是组件内？                         | 出现第 2 份相同 `useEffect` 模式 → 立即抽 `hooks/`（**「二八定律」：第二次出现就抽象**）       |
| 数据放 `data/` 还是 `config/`？                      | 内容型（产品、FAQ、导航、价格）→ `data/`；开关型（站点 URL、统计 ID、Feature Flag）→ `config/` |

### 13.16 静态导出「首屏闪现」排查：删除 `app/loading.tsx` ✅（2026-09-21）

**现象**：用户反馈每次刷新页面，页面顶部居中会闪现两个淡色小圆角块（形似"!"），随即消失。

### 13.20 修复 MegaMenu 悬停切换的闪烁（2026-09-22）

**现象**：PC 端鼠标悬停顶部导航（如「人工智能与应用」）时，下拉面板内容区闪烁抖动。

**复现与测量**（本地 dev + DOM 采样）：鼠标在左侧分类导航上换个分类，内容区就整块
**「淡出到全透明（~170ms）→ 淡入（~150ms）」= 约 320ms 空白**；不同分类内容高度不同时面板还会跳变（480 ↔ 523px）。

**根因**：`MegaMenuPanel` 内容区被包在 `<AnimatePresence mode="wait">` + keyed `motion.div`
（opacity 0→1）里，卡片另有一组 stagger 入场动画。这套"优雅切换"适合**点击式**切换；
而左侧分类是 **hover 切换**，鼠标扫过每个分类都会触发一次完整退场/入场。

**修复**：内容区改为**即时渲染**——移除 AnimatePresence 与全部入场动画（含卡片 stagger），
鼠标划过分类时内容瞬换；同时删除不再使用的 framer-motion 导入与 variants。

**验证**（dev 实测，5 个菜单 × 各自全部分类 + 搜索过滤路径）：

- 切换全程内容区 opacity **恒为 1**，无空白帧
- 面板高度只随内容自然变化，无动画性抖动
- `tsc` 0 error；搜索过滤同样即时无闪烁

> **规则（写进规范）**：**hover 驱动的切换一律不做退场动画**——"退场+入场"会让
> "划过即切换"变成"划过即闪烁"。需要过渡感时用点击式切换或单次入场（如面板打开时），
> 不要挂在 hover 上。
