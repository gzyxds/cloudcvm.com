## 首页楼层组件模块分析

对 `src/app/page.tsx` 及其引用的 18 个楼层区块做了完整梳理，产出 `开发文档/首页楼层组件分析.md`。

核实到的关键事实：

- 首页 = Header + VideoCarousel + 18 楼层 + Footer；楼层分布在 `sections/home`(10) 与 `sections/shared`(8)
- 加载策略双轨（page.tsx 注释有依据）：**首屏 9 个静态导入**（Hero/ServiceTabs/Price/PrimaryFeatures/Leftright/Rightleft/Solution/TwoColumnShowcase/Scenario），
  **首屏以下 9 个 `dynamic()` 懒加载**（CapabilityGrid/BentoGrids/Advantage/Testimonials/Customer/Zone/Faqs/LogoClouds/CatSections）；
  原因：静态导出下 dynamic 的 loading 骨架会被烘焙进首屏且高度塌缩 → hydration 下跳（CLS）
- 楼层统一骨架：`<section>` + `ui/Container`(max-w-1800) + 标题区 + 主体区；标题区未收敛（`ui/SectionHeader` 仅 AI 页用）
- 交互 4 类：Tab+悬停防抖（共用 `hooks/useDebouncedHover`）、横向手风琴（Solution/PrimaryFeatures/BentoGrids 三处重复未抽）、
  scroll-snap 轮播（仅 Scenario）、左列表右预览联动
- 18 楼层仅 2 个是服务端组件（LogoClouds、Testimonials），其余带 `'use client'`
- 动效仅 `Scenario` 做了 `useReducedMotion` 降级

技术债（按优先级）：
1. **P1 色值双轨**：品牌令牌 `#3860f4`(brand-500)，但 CapabilityGrid/Scenario/Customer/Rightleft/CatSections 硬编码 `#0055ff`/`#1664ff`/`#0052d9` 等
2. **P2 骨架高度写死 400px**（LogoClouds 200px）→ 懒加载楼层仍有 CLS
3. **P2 横向手风琴三处重复**（Solution/PrimaryFeatures/BentoGrids）
4. P3：锚点 id 不统一、图标库 heroicons/lucide 双轨、数据内联、文件偏大

回答「配色是否都用 tailwind.css 默认 token」时做的全量统计（`grep` 统计 `src/**/*.tsx`）：

- **结论：不是。令牌存在但采用率低，属「双轨制」**——规范体系是三层：
  ① `src/styles/tailwind.css` 的 `@theme` Design Token（brand-50..950 主色 #3860f4、neutral、`--radius-sm..4xl`、`--shadow-*`）
  ② 组件/语义层：`ui/Button`(5 变体)、`ui/Container`(max-w 1800)、`ui/SectionHeader`、`layout/navStyles.ts`、`@layer components`(.btn/.card-base/.glass-surface/.section-gradient-*)
  ③ 页面（48 路由）
- 实测：**语义令牌类合计约 485 次**（text-brand 160 / text-neutral 147 / bg-brand 142 / bg-neutral 36），
  **原始色板类合计约 3336 次**（text-slate 915 / text-gray 678 / border-slate 330 / bg-slate 326 / bg-gray 257 / text-blue 256 / border-gray 253 / bg-blue 252 / indigo 15）
- **硬编码 hex：1496 处，散布 66 个 tsx 文件**；重灾区 `sections/shared/PriceCard.tsx`(240)、`app/eccloud/page.tsx`(173)、`app/contact/page.tsx`(110)
- 圆角无统一档位：rounded-md 249 / rounded-lg 254 / rounded-xl 126 / rounded-full 380 / rounded-2xl 25 / rounded-sm 112 / rounded-none 27 混用
- 间距靠手写：py-24(153)/py-16(138)/py-20(67)/py-32(23)、px-4(184)/px-6(190)/px-8(114)，无 spacing 令牌
- 公共组件采用率：Container 61 文件、Button 26 文件、SectionHeader 仅 14 文件；仍有 32 个页面直接手写 `mx-auto max-w`
- `navStyles.ts` 是唯一「禁止硬编码色值」的示范文件（3 文件引用）
- ESLint 无任何样式/token 强制规则（只有 any/no-var 等），无法阻止新增硬编码
- 已有文档记录此问题：`开发文档/代码规范与优化方案.md` §4.5、`开发文档/首页楼层组件分析.md` §五 P1
